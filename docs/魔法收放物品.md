# 魔法收放物品

空手取物时，物品先隐藏 0.05 秒，再用 0.25 秒从脑后绕到悬浮位置，角光同时从根部亮到尖端。前 0.10 秒完成从零到正常尺寸的缩放，到位后保留惯性。第一人称使用画面侧边路径；收回空手时倒放路径，在最后 0.10 秒缩小，结束后直接隐藏。

- `MagicEquip` 按玩家、主副手记录实际空手状态，角光使用双手合并状态。第一次看到已持物的玩家不补播入场，切换视角也不重播。
- `MagicEquipMotion` 提供可逆的 0.25 秒运动包络和左右镜像路径；仅从完全隐藏处开始飞入时额外等待 0.05 秒，总计 0.30 秒。快速收放从当前进度反向，不跳到另一端，中途反向也不重新等待。
- 非空物品之间的切换继续使用原版流程，不新增入场。数量、耐久变化不重播。
- F 主副手交换按前后两手物品内容互换识别，直接切换并重置旧手的惯性；不重播入场、退场或亮角，短暂覆盖第一人称旧物品缓存/装备进度以避免出现第二次换手动画。
- 收回只暂存一份显示用 ItemStack，0.25 秒包络完成、返回起点后停止绘制并清理；不更改背包、实际使用状态或物品实体。
- 第一人称空手收放结束后，等原版显示物品和装备高度真正就绪再交回，避免 0.25 秒结束时再次下沉。F 键即时换手仅短暂覆盖；非空换槽立即释放交接，普通挥动及使用动作保留。
- 世界切换、断线、玩家离开、死亡、隐身、关闭替换模型等清理状态。按已保存外观判断角开关，不读取编辑草稿。
- 飞入/飞出是主动路径，其自身只以第一人称 18%／第三人称 24% 的权重驱动世界坐标弹簧，避免弹簧反向抵消整段飞行而出现中段顿挫。物品到位后仍有轻微惯性回稳，不额外叠加固定正弦摆动；玩家跑跳、转身的惯性参数不变。
- 收放进度使用统一的小数游戏时钟；同一 tick 的较早采样不回拨时间，首次渲染观察到变化也不会直接跳过最多一整 tick 的入场。
- 尺寸变化只作用于最终物品绘制坐标，物品光晕随之缩放，不缩小飞行路径。地图使用原版地图绘制入口；普通物品、地图及第三人称在接近零尺寸时直接跳过绘制，不把奇异缩放矩阵传入光晕或法线计算。
- 飞入/飞出期间不新增运动拖尾，物品到位后接入按速度变化的拖尾；原有使用期间的幅度限制和位置安全上限保留。
