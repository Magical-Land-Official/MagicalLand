# 嘴咬与蹄托持物

[文档目录](../README.md)

无角小马用嘴或前蹄拿物品，有角角色使用魔法持物。

## 当前表现

- 工具、剑、三叉戟等用嘴咬住柄。主手优先使用嘴，另一件工具改用前蹄，避免两件物品占据同一嘴部位置。
- 其他物品由对应前蹄托住；盾牌附在前腿外侧，左右手设置仍然生效。
- 托物姿势取现有起飞动画的蜷腿角度和关节补偿，整体转到前方，让蹄底朝上。拿起与放下都直接切换姿势，不再插值整条腿的翻转过程；肩部另有最多约 3° 的短动作提示。
- 取出或更换嘴咬物品、从蹄托改为嘴咬，以及从嘴咬收回到完全空手时，轻点头约 2.5°，一次约 0.3 秒。嘴咬改为蹄托时不点头；数量变化也不触发。
- 嘴咬物品攻击时，头部最多轻摆约 6°、轻点约 3°，不改变玩家视角、判定或攻击距离。
- 食用、饮用时，拿着该物品的整条前腿从肩部抬起，并轻微起伏；食用约抬 24°，饮用约抬 28°，肩部同时向内旋转最多约 8°，让物品靠近嘴部中线。开始和结束都有过渡，小腿与蹄子的相对角度及关节补偿不变。支持主副手和左利手。
- 独角兽第三人称吃喝时，当前使用的物品悬浮到嘴边，随实际头部姿态移动。食物轻微起伏、饮品略倾斜，结束后回到普通持物位置；换成另一种物品会清掉旧吃喝动作，非使用手保持原样。
- 第一人称隐藏人类手臂，物品位置与使用动作沿用原有实现，独角兽的魔法惯性保留。
- 托着物品的前蹄不播放落蹄声，其余腿继续按原步频播放。

## 维护与验收

无角持物分工在 `PonyHeldItems`、`PonyHeldItemPose` 与 `PonyCarryCue`。物品挂在当帧头部／蹄子的实际变换上，跟随转头、动作和身体移动。骨骼修改只在本次渲染内有效，结束后恢复。

独角兽吃喝使用 `PonyMagicConsumption`。`PonyRenderer` 捕获当帧嘴部挂点，第三人称物品层同时移动绘制位置和惯性目标，保留已有魔法光效及持物惯性。第一人称沿用原版吃喝动作。

独立检查覆盖物品分类、主副手、原有子关节补偿、蹄底朝向、食用／饮用识别、整臂抬起方向、动作中断、不同渲染频率和骨骼状态恢复。

初版食用动作通过 160 份源码的 Java 17 编译与 780 项持物、动画检查，随后完成构建及体验验收。该轮不包含后来的瞬时托蹄、掏收提示、肩部内收和独角兽吃喝。

持握调整已提供测试版；其后的点头修订曾限制为嘴咬与完全空手之间的切换，物品切换清除残留点头。该修订通过 162 份源码类型检查、1,855 项持物与骨骼检查、7,181 项掏收时序检查，记录时尚未重新打包；魔法吃喝沿用此前 3,209 项状态和矩阵检查的实现。此处为历史结果，现行点头规则见上文。

第三方异形物品可能需要单独的偏移预设；弓弩拉弦等第三人称动作后续再细化。
