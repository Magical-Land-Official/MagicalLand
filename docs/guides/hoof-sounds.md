# 马蹄声

小马行走、奔跑、倒走和蹲行时，按现有动画的落蹄节奏播放马蹄声。近乎同时触地的蹄子合为一声，避免音量叠加；蹲行会随动画放慢，声音也更轻。第一人称看不到身体时仍会播放。

声音采用 Minecraft 自带的马蹄素材。木板、石头等硬地与草地、沙地等软地使用不同音色，地毯进一步减弱音量；音量跟随设置中的“玩家”分类。涉水、游泳、骑乘和飞行沿用各自原有声音，人类玩家、动物及怪物不受替换影响。

## 联机去重

Magical Land 服务端通过原版“实体声音”消息发送脚步，标明发声玩家。支持此功能的客户端在确认对方为小马后，以落蹄声替换原脚步；普通客户端仍播放原声。

玩家尚未进入实体追踪范围时，服务端保留原版坐标声音。服务器未安装 Magical Land 或版本过旧时，只替换自己的脚步，其他玩家保持原声。

这项功能只调整声音，不改变移动、潜行判定或原版 `STEP` 游戏事件。幽匿感测体等机制继续使用原版规则。

## 调整动画时

触地点记录在 `PonyHoofCadence`，对应 `mare_animation.json` 的作者帧。它们用于声音节拍，不是脚底的物理碰撞判定。修改步态或片长时，应一起复核触地点；无需往动画里加入播放声音的关键帧。

世界模型播放时会提供实际相位，声音统一在客户端 tick 中调度。背包、编辑器预览和额外渲染不会重复发声；切换动作、传送或长时间没更新后，也不会补播积压脚步。
