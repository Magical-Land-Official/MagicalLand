# 自动眼仁注视

眼仁会自动看向附近实体，头部、镜头和表情保持各自的控制方式。默认启用，可在设置的游戏页关闭“眼仁自动注视”；开关只影响本客户端看到的小马。

## 目标规则

固定优先级：最近攻击过自己的实体 → 敌对实体 → 其他玩家 → 中立生物 → 友善生物。同级选最近；只有距离差不足 0.2 格时保留原目标，避免反复切换。更高优先级不受该缓冲限制。

- 范围为玩家到实体的三维直线距离 8 格，含边界。
- 最近攻击者使用原版记录的最后一个攻击者，优先权保留 100 tick（正常 TPS 下 5 秒）。记录过期后按该实体普通分类处理。
- 只考虑活着的玩家和生物，不看自己、旁观者、盔甲架、掉落物、经验球。睡眠、死亡、旁观状态的小马不选目标。
- 隐身实体一律排除，即使同队或有其他显示效果也不作为目标。另检查针对该玩家的不可见状态。
- 从玩家眼部向目标眼部发出 `VISUAL` 射线，忽略液体，排除被方块或其他可见生物碰撞箱遮挡的目标。此处按眼部射线判断，不做像素级遮挡分析。
- 搜索限定在玩家头朝向左右各 100°，与第三人称相机方向无关；眼仁移动仍受模型朝向与幅度限制。
- 中立生物明确以自己为攻击目标、或对自己愤怒时提升到敌对。兼顾普通攻击目标与 Brain 的 `ATTACK_TARGET` 记忆。

默认中立分类涵盖原版 `Angerable` 生物及猪灵、山羊、羊驼、行商羊驼、熊猫、海豚。其余带 `Monster` 标记的生物归敌对；其余生物归友善。蜘蛛按敌对类别处理，不额外预测白天、亮度等情境。第三方生物可能需要补充分类。

可用数据包扩展 `magicaland:gaze_hostile`、`magicaland:gaze_neutral`、`magicaland:gaze_friendly` 三个实体类型标签。最近攻击者、已确认针对自己的攻击状态优先；显式敌对标签高于友善和中立标签，友善标签可覆盖默认类别。不要同时把同一类型加入多个标签。

## 表情与移动

`assets/magicaland/expressions.json` 的表情定义增加 `gaze`：

- `auto`：允许自动注视。当前只有普通表情启用，因此使用普通眼的动作可以注视。
- `locked`：保留作者编排的眼神。向后看、向下看、下落过渡、挥手、芭蕾使用此模式。
- `off`：不添加自动眼仁移动。现有笑眼、闭眼、挤眼及独立生气眼型使用此模式。

未填写 `gaze` 的旧资源包默认锁定，避免覆盖作者眼神。一个动作引用先播后循环的两个表情时，两者都允许才会启用；因此当前下落过渡动作整段让位于原演出。修改映射不必编辑身体动画。

每个 `eye_styles` 条目增加 `gaze_limits`，单位为模型像素：

| 眼型 | 左眼向外 | 右眼向外 | 向上 | 向下 |
| --- | ---: | ---: | ---: | ---: |
| 01 | 1.20 | 1.20 | 1.05 | 1.20 |
| 02 | 1.20 | 1.20 | 0.45 | 1.20 |
| 03 | 0.60 | 0.65 | 0.85 | 1.20 |

左右以角色的 `left_pupil`／`right_pupil` 骨骼为准。默认眼位沿用模型原本向内聚拢的姿态，动态注视在此基础上偏移：向外使用上表幅度，向鼻梁最多移动 0.15 模型像素。03 的左右眼框分别适配。无注视输入时回到默认眼位；捏马预览使用[独立的鼠标跟随](preview-idle.md)，锁定表情优先保留作者眼神。

水平与垂直合用椭圆限位，不在对角线叠出过大位移。每个眼型可在 `gaze_limits` 中增加 `left`／`right`，分别填写 `outward`、`up`、`down`；`outward` 表示向外水平幅度，已适配裁剪的眼型向内另受 0.15 上限约束，且不超过该眼型本身的水平幅度。省略时继承通用上限，不需要增加动画轨道。数值必须在 0–2.5 模型像素以内，单眼配置不得超过通用上限。

眼眶裁剪从父眼型骨骼的真实眼白面提取固定窗口，03 的重叠白块先求并集，02 窗口在前置眼皮处结束。先应用眼仁当前的位移、缩放和旋转，再在眼眶局部坐标中，按窗口裁掉越界的虹膜、瞳孔和高光。裁剪边缘的 UV 通过插值计算，以保留原有渐变。眨眼缩放不再反向压小注视幅度，而由固定窗口遮去越界部分。

裁剪复用原有渲染层与深度规则。无法识别的眼眶窗口会缓存回退结果，保留原眼位并采用单侧小幅移动：水平不超过 0.3、向上 0.15、向下 0.2 模型像素，以适配未知资源包。

方向响应在水平约 45°、垂直约 22° 达到满幅（斜向仍受椭圆约束）。超出窗口的部分不提交绘制，仍保留动作幅度上限，避免整只眼仁离开眼眶。

注视方向通过实际渲染矩阵换算，包含身体转向、头部动画和飞行侧倾。只在世界中的玩家模型渲染时启用；标题、捏马预览不追踪世界实体。平滑按游戏时间推进，不按渲染次数推进；目标丢失后缓慢回正。临时骨骼状态在面部绘制结束后恢复，异常退出亦恢复。

## 无目标时的转向预看

没有有效实体目标时，`PonyTurnGaze` 根据被渲染玩家头部朝向（`headYaw`）／视角俯仰（`pitch`）的转动速度，让眼仁轻微看向转身、抬头或低头的方向；输入与头部视角渲染一致，远端不会把独立的身体转向误当成抬眼方向。停止转动后经原有平滑器回正，不根据绝对头角度持续偏眼。水平最多使用当前幅度的 60%，垂直最多 35%；与实体注视共用双眼移动及眼眶裁剪。

实体目标优先于转向预看，两者不叠加，并共用平滑器衔接位置。锁定眼神、笑眼／闭眼、后退回头和自动注视开关继续约束预看。

先在 tick 间插值玩家朝向，再按游戏时间计算实际转动速度，远端的逐 tick 更新也不会因帧率越高而把预看幅度挤成短脉冲；重复绘制不重复推进，跨 ±180° 使用短角差。每个玩家和世界独立保存采样，重生、换世界、时间倒退、超过 5 tick 未采样、单次位置跨越 4 格或异常大幅角度跳转时清空预看和平滑状态，避免传送、恢复渲染时甩眼。该功能不改变身体转向同步，远端身体朝向差异见[历史记录](reports/2026-09-09-gaze-history.md#历史记录传送后的远端身体朝向差异)。

## 联机与性能

支持新版服务端时由服务端选目标，客户端再次检查范围、隐身与视线，再渲染眼仁。不接受客户端指定攻击者或注视目标。每 5 tick 重选目标，按优先顺序验证候选视线，找到可用目标即停止；每 tick 验证已有目标。目标变化发送消息，每 40 tick 补发一次。消息只含源玩家、维度、目标实体 ID 与 UUID，不逐帧发送坐标。

目标消息通过独立的 `magicaland:gaze_v1` 服务端单向通道发送给自己，以及正在追踪该玩家且支持该通道的客户端。关闭外观广播时仍能得到自己的服务端判定，但不向其他玩家广播自己的注视状态。客户端验证 ID 与 UUID 同时吻合，避免实体 ID 复用导致看错人；切换世界、断线及过期消息会清理状态。

旧版或未安装模组的服务端缺少攻击者与仇恨同步，客户端按可见实体的分类和距离选择，保留原版中立类型回退。此时最近攻击者及中立生物的攻击状态可能不准确。
