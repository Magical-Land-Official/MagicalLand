# 鬃毛与尾巴左右镜像

前发、后发、尾巴各有独立的“左右镜像”开关，位于对应部件的款式池上方。镜像保留款式编号与颜色联动，主预览和缩略图同时显示新方向。缩略图使用固定示例颜色。

`ModelConfig.frontManeMirrored`、`backManeMirrored`、`tailMirrored` 默认为 `false`。开关随预设保存、复制和同步；编辑期间其他玩家看到已应用版本，保存后才更新。

## 渲染处理

在 `FrontMane`、`BackMane`、`Tail` 组件根的父空间做 X 反射。连接轴均为 X=0，连接位置保持不变；所有子骨骼和当前动画姿态作为整体翻转。

反射作用于绘制矩阵，源资源和共享骨骼保持原样。UV 随顶点移动，手绘纹理、明暗和挑染一起翻转，复用原调色纹理。

Minecraft 1.20.1 的 `MatrixStack.scale(-1,1,1)` 带有法线矩阵负行列式归一化，不适用于这里的单轴反射。因此分别反射位置、法线矩阵，并反转顶点绕序，以保持背面剔除、光照和材质参数。绘制结束或异常时恢复父矩阵与镜像标记。

自动取景使用静止组件的反射结果。取景和缩略图缓存均包含镜像标记，非对称发型换侧后会重新取景；动画姿势仅用于实时绘制。

## 验证与注意事项

以下为实现阶段的离线验证记录，测试源码在本地维护：

- `tests/mane/ManeMirrorTest.java`：实际模型的全部三个组件子树、五组关节/父级姿势，检查位置、法线、绕序、UV、颜色/光照参数，以及共享模型与矩阵恢复。
- `tests/gui/ManeMirrorPreviewTest.java`：逐个现有发型和尾巴检查静止取景、镜像缓存、缩略图方向与固定素体颜色。
- `tests/mane/ManeMirrorDraftTest.java`：未保存不落盘不联网、取消、独立开关持久化、预设复制不互相修改。
- 既有 `PreviewGeometryBoundsTest` 同步回归通过。

完整镜像会把尾尖左摆变为右摆，并翻转贴图中画好的非对称光影；父级头部和身体动作保持原样。当时未完整构建或启动游戏，游戏内遮挡、外观和操作体验未验收。
