# 款式缩略图维修（2026-09-08）

前发、后发、尾巴和眼型卡片使用固定示例配色：白色素体、柔和紫灰鬃毛、默认蓝色虹膜。玩家配色与挑染显示在左侧主预览中。

## 修复内容

- 当时的缩略图缓存键包含部件、款式编号和图像尺寸，调色不会使缓存失效。后续镜像功能加入了镜像标记，见[左右镜像](mane-mirroring.md)。
- 图像最长边限制为 192 像素，等比缩放并居中绘制，修复宽卡片横向拉伸的问题。
- 创建、绘制或释放离屏图后，恢复进入操作前的绘制状态：读/写帧缓冲、视口、裁剪、纹理绑定、混合、深度、颜色写入、着色器和顶点缓冲。帧缓冲恢复为调用方的目标。
- 卡片使用 GUI 标准方向光，主预览单独管理光照。
