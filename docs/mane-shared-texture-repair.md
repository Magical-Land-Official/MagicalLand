# 其余发型共享纹理维修

2026-09-09：整理前发 02–08、后发 02–06/08、尾巴 02–07 的灰度纹理与六区遮罩，共 19 个部件。01 保留原 UV、纹理与遮罩；后发 07、尾巴 08 留空。

## 资源与复用

- 鬃毛图集为 256×256，模型逻辑 UV 为 128×128；沿用原造型与动画。
- 1566 个面映射到 1138 个纹理块，428 次面映射复用已有块。只允许明暗近似且同款色区不冲突的面复用；不同款式可以共用灰度像素而使用自己的遮罩。
- 图集中的既有身体预览区域及 01 区域被保护。新块含一像素边缘延展，避免采样到透明空隙。大块发片和细小厚度面按实际尺寸分配 UV，保持粗像素质感。
- 灰度先表现整体明暗和表面朝向，再叠加沿发束长轴的纤维细节。极端色阶会放大重复色块和明暗断层。
- 六区沿发束局部横向排列，随发块转弯。连续主卷保持相同横截面色序，小发片继承对应子区间。遮罩保存到静止 UV，随骨骼运动，独立于灰度明暗。

`Style07FrontManeHighlight` 含有效发片，需要保留；这些面使用灰度图和分区遮罩着色。

## 沿发流分区修订

沿发流修订保留既有灰度笔触：1566 个面中，123 个面调整 UV，其中 44 个主发束面横向最近邻扩采样，以容纳六条可见色带；其他面读取的 RGBA 保持一致。拆开 11 个冲突块，兼容部分继续复用，并移动少量纹理块腾出连片空间。图集仍为 256×256，01 与身体预览区域保持原样。

`Resources/ManeDyes/flow-layout.json` 保存 261 个发块的源坐标：`u = u + (local[axis] - center) * slope`，再分为六区。03/06/07 共用冠部发流，侧卷逐段传递横向色序；07 额外薄片继承底下主片的子区间。06 尾尖的横向坐标随方块侧转，避免尾尖沿长度依次变色。02/05 碎发及 04 短卷沿各自局部方向分区，08 丸子头沿其倾斜发块方向铺带。

遮罩生成工具在本地维护，使用 Node.js，无额外依赖。取得对应工具后，按其本地目录运行：

```text
node tools/generate-mane-dye-masks.mjs --check
node tools/generate-mane-dye-masks.mjs --write
```

默认检查，`--write` 同时导出源目录与运行时的 02–08 遮罩，范围限于遮罩 JSON。工具拒绝空色区、过期发块记录、同款同部件共享 UV 冲突和边缘冲突。改 UV 或发块后，先同步 `flow-layout.json` 并拆开冲突 UV，再导出。发流参数取自局部几何。

运行时整部件与色带的镜像见[左右镜像](mane-mirroring.md)。

## 纤维素材来源

灰度纤维源由 imagegen 生成，降采样后按表面朝向、发流和三阶色调装入图集。素材采用 32×32 粗像素风格，纵向不规则发丝、少量 1 像素断笔，主灰度为 225–250/255，沟纹为 200–220。整体亮度较均匀，局部光影由模型对应区域补充。
