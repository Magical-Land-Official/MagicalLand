# 独立外观同步服务：后续备选

状态：备选方案，尚未实施。现行外观同步由 Minecraft 服务器上的 Magical Land 提供，与客户端使用同一个 JAR。

若要在未安装服务端组件的服务器上互见自定义外观，可将配置发布与获取改为独立服务。现有公共 API 是模组内接口，不提供跨客户端通信。

第一版仅同步保存后的外观配置，包括颜色、挑染、镜像和左右可爱标志；客户端继续本地渲染，不上传每帧动画、眼仁或物理状态。Gameplay 能力、库存与交互仍由游戏服务器负责。

必须解决：

- 账号归属验证，不能仅相信客户端自报 UUID；不得收集玩家游戏登录令牌作为简易替代。
- 更新通知、首次读取、缓存、限流、数据大小和版本校验。
- 停止发布、撤回与隐私说明，明确数据保留范围。
- 断网时保留本地外观及缓存，不阻塞游戏线程或进服。
- 防止旧请求覆盖新外观，断线、切服、资源重载时清理任务。

首次遇到未缓存玩家可能短暂显示默认外观，保存更新也可能有传输延迟，但不应影响帧率或动作流畅度。移除游戏服务端支持会失去真实仇恨等辅助注视信息，客户端只能近似判断，不能保证所有观察者眼神一致。主动表情/特殊动画同步需另行设计。

实施前需评审身份验证、维护成本、隐私与验收标准。
