# 文档维护

首页介绍功能、安装和常用入口，具体操作放在玩家指南中。文档索引按玩家说明、开发资料、历史报告与规划分类；Gameplay 的正文维护在其仓库。

公开文案使用正式名称 Magical Land／魔法大陆。版本与兼容组合集中在首页安装说明和公共 API 文档维护，其他页面链接引用。

## 文件位置

- 新的玩家指南放在 `docs/guides/`。
- 开发方法和公共接口说明放在 `docs/development/`。
- 独立测试报告使用 `docs/reports/YYYY-MM-DD-主题.md`。
- 规划明确标注状态，避免与现有功能说明混淆。
- 旧文档继续保留原路径。以后移动文件时，一起更新内部引用；对外分享过的路径保留跳转说明。

## 报告内容

记录日期、对应提交、测试环境、复现或执行方法、结果、未测项和后续问题。跨仓测试同时记录两仓提交。

独立编译、逻辑测试、构建、开发客户端启动、人工验收与多人实测分别填写。历史报告保留当时观察；修复后追加新记录和链接。

## 测试与附件归档

仓库保留其他开发者维护的协作测试及必要替身，不因个人测试转为本地维护而删除。个人回归测试与临时工具放在本地工作区的 `tools/tmp/` 中；独立测试不由 Gradle 自动运行。旧报告中的测试路径反映当时布局，复跑时向维护者取得对应测试。

仓库保存精简报告、精选截图和素材授权记录。截图标明来自游戏、离线预览还是示意图。原始日志、批量截图、视频、实验备份、构建缓存、依赖副本、临时启动参数、测试世界和个人配置留在本地；正式 JAR 使用版本发布入口。

公开前检查文件中的个人信息和访问凭据。原始证据中的本地路径可帮助作者查证，正式使用说明采用仓库相对路径或清楚标注的示例路径。
