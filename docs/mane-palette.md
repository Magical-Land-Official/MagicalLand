# 鬃毛与尾巴调色

2026-09-07：前发、后发和尾巴接入自动色阶调色，使用原有灰度贴图与 UV。

## 玩家操作

- 默认使用色阶调色。前发为主配色，后发和尾巴各有一个联动锁；锁定时整套主色、阴影和高光跟随前发。
- 解锁后发或尾巴时复制当前配色及阴影/高光锁状态，随后可独立调整。
- 阴影和高光默认自动计算。解锁保留当前颜色，主色再变时手选色保持不变；重新锁定恢复自动计算。
- 后发或尾巴重新锁定后跟随前发；再次解锁会复制当时的前发配色，覆盖上一次独立配色。
- 当前界面在“鬃毛”分类中分别选择前发、后发或尾巴；重新锁定对应的阴影、高光即可恢复自动计算。
- 传统乘色保留部位联动，停用阴影/高光色阶。切回色阶调色时保留手选值。

## 实现与兼容

- `ManePalette` 处理骨骼部位映射、联动、解锁快照和配色读取。`BodyColorRamp` 将灰度映射为与身体一致的自动色阶，直接输出最终颜色。
- `ManeTintTextures` 读取资源包中的 `textures/entity/mane.png`，按实际主色/阴影/高光三元组缓存整张调色纹理。未开启分区时三处同色共享同一张缓存；开启分区时再按部件、实际款式遮罩和六区色阶隔离，允许不同发型复用同一基础 PNG 而不串染。
- 缓存上限 128 项、64 MiB（按 CPU/GPU 双份像素估算），空闲回收；资源重载、断开连接和退出时释放。失败或容量不足时回退为使用同一联动主色的传统乘色。
- `ModelConfig` 保存 `maneShadingMode`、两处联动锁、六个阴影/高光色及各自的锁。`maneColorLinkVersion` 标记一次性的联动迁移，不是发型编号版本。
- 无迁移版本的旧配置：已有不同主色的部位保留为独立状态；相同 RGB（兼容六位及八位十六进制）设为联动。规范化后版本为 1，后续加载/保存不会重新猜测联动状态。
- 本地保存、界面预览和远端模型使用同一配置，通过整对象 JSON 同步。保存时联动主色也写入旧颜色字段；旧客户端只能读取主色，联机显示一致需使用相同新版。
- Blockbench 保存灰度源图，玩家配色由运行时生成；`BaseTextureBackup` 仅供工程预览。
