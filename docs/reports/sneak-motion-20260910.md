# 蹲行动画随步速调整

为 Gameplay 的慢蹲感知配套，移动蹲行动画 `sneak` 改为按原版实际位移更新播放速度。普通平地蹲行约为原速，移动减慢 20% 时步频也相应降低。本体和其他玩家使用同一计算，无需新增同步字段或 Gameplay 依赖。

静止蹲姿、其他主动作、眨眼、表情、耳朵、尾巴和编辑器预览不变，也未修改 Blockbench 项目或动画资源。修改入口为 `GeckoPlayerAnimatable` 的主动作控制器，新增 `PonySneakController` 管理连续局部时间。

GeckoLib 4.8.3 的直接倍率会重新缩放已播放时间。这里仅改变后续时间增量，防止减速瞬间倒跳；循环、关键帧与过渡使用同一条局部时间轴，仍由原控制器处理。

## 验证

`tests/render/run-sneak-tests.ps1` 使用真实 Gecko 类检查原倍率反跳复现、连续减速、同帧重复处理、1 倍速等价、混合倍率、循环、停止与切换。提供已有 named 主模组类路径时，同时对两处生产类完成 Java 17 类型检查。测试不运行 Gradle 或 Minecraft。

独立检查通过，结果位于 `work/earth-sense-20260910/sneak-animation-tests`。随后完成双包构建并启动原测试世界，体验验收通过；当时未覆盖多人远端玩家与不同移动修饰效果。
