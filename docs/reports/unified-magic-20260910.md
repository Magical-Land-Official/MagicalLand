# 2026-09-10 光效统一、远控瞄准与悬浮前小腿

## 本轮变更

- 角、悬浮物品、拖尾、包身光改用同类宽幅不规则光纹。物品保留实际纹理透明剪影，星星保留现有数量和节奏。
- 空手出窍显示柔光核与收尖焰尾。尾部随实体实际移动反向延展，运动按 tick 采样，传送或换世界清理。
- Gameplay 的 Mod Menu 设置页提供能力视角：自动背面第三人称／沿用发动前本体视角。只在接管相机时应用一次，F5 和返回本体的视角恢复保留。设置独立保存，并只读迁移此前放在外观配置中的选择。
- 第三人称持物向观察镜头侧边偏移 0.30 格，左手镜像。准星显示原交互射线的屏幕落点，冷却条随准星移动；实体、碰撞、射线和服务器交互规则不变。
- 前腿恢复整条蜷曲，使用原姿态的 95% 旋转和同倍率位置补偿；普通无翼悬浮从腿根放低约 30°，冲刺平滑抬回原高度。升降惯性只在根部附加最多 ±4°，后腿维持原规则。取消此前的前两节 35% 和蹄部独立反解实验。

## 资源与版本

Magical Land 开发版本 0.3.3，公共 API 1.3；Gameplay 开发版本 0.2.2，要求主模组 `>=0.3.3 <0.4.0`。新增 `AppearanceVisuals.renderFlame`，Gameplay 仍只依赖公开 API。能力视角设置、按钮和配置测试已移到 Gameplay；删除尚未发布的主模组偏好接口及对应桥接，F9 保持原有设置。

飞行来源为 `src/main/resources/assets/magicaland/animations/mare_animation.json` 的 `fly` 第一帧。`internal.levitate` 由代码派生，没有单独的动画资源。前小腿为 `LFrontCalf`、`RFrontCalf`，倍率位于 `PonyFlightMotion`。本轮未改模型、UV、贴图、Blockbench 工程或动画 JSON；修改 `fly` 会同时影响有翼飞行。
