# 独角兽飞行屏幕边缘光罩

## 本轮内容

为本体视角新增一圈柔软、缓慢流动的魔法边光。它跟随已应用的魔法颜色和现有飞行魔法进度，在起飞时渐亮、落地后淡出。光圈集中于屏幕外缘，中心不铺遮罩。

适用于开启小马替换、实际显示有角无翼的角色。初版体验验收后，显示范围收紧为第一人称本体视角；第三人称、界面、隐藏 HUD、非本体相机和外部第一人称绘制不显示。使用 Magical Land 的解剖覆盖和飞行状态，无需 Gameplay 依赖。

现有包身光、角光、动画、模型、贴图、同步和飞行权限保持不变。新增绘制使用普通界面顶点，不增加世界后处理或深度操作。

## 验证状态

两个新增类与客户端入口通过真实 Minecraft／Fabric／主模组依赖下的 Java 17 类型检查。统一飞行回归通过：运动 109,416 项、派生动画 1,931 项、边光数学与网格 943,892 项、真实界面层及接入守卫 17 项；独立复核未发现必修问题。

几何预算固定为 512 个四边形、2,048 个顶点；最深内缩约占短边 8.68%，最大透明度 0.15，中央无几何。真实 1.20.1 界面层使用颜色写入掩码，不写深度。新增 HUD 采样不会重复推进飞行动作。

回归入口为 `tests/render/run-flight-tests.ps1`。首轮独立检查时未记录光罩的实机表现，后续构建与验收见下文。

## 后续构建与视角调整

初版光罩与慢蹲动画构建到 Magical Land `0.3.4+sense-moving-test-20260910`，搭配 Gameplay `0.3.2` 启动原测试世界，体验验收通过。

视角限制在验收后加入：切到第三人称立即隐藏并清理入场进度，切回第一人称重新柔和进入；第三人称角色包身光不变。该限制通过独立检查，但当时尚未重新构建进测试游戏。
