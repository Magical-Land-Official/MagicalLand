# 颜色二级菜单

2026-09-08：高光和阴影控制改为颜色行下的折叠子项，沿用原有色阶与配置。

## 操作与范围

- 身体公共色阶、前发、独立后发和独立尾巴的颜色行左侧提供展开三角。阴影、高光子项缩进 12 像素，锁控制自动或手动色阶；点击色块打开取色器。
- 进入页面时默认收起；同页切换锁、调色模式、恢复自动时保留展开状态。返回其他页再进入时重新收起，展开状态不写入玩家配置。
- 后发和尾巴锁定时，整组配色跟随前发，独立色阶子项隐藏。解锁后可展开并分别调整；重新锁定后，再次跟随前发并收起独立子项。
- 身体共用一组手动色阶，异色肢体自动计算明暗；传统乘色模式隐藏色阶子项。
- 身体“全部恢复自动”位于身体子菜单。当前鬃毛页面通过各阴影、高光的锁恢复自动计算。
- 同页刷新在下一帧执行，避免在点击分发中途替换列表。恢复当前滚动位置和焦点行；列表缩短时按有效滚动范围限制位置，切页仍重置。
- 聚焦颜色行后，右方向键展开、左方向键收起，Enter/空格切换；支持朗读提示。过长标签截断在锁图标和色块之前。
